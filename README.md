# Simple Slip Captcha

一个基于Java Spring Boot + Vue3 的简单滑动验证码

## 项目简介

Simple Slip Captcha 是一个提供滑动验证码功能的项目，使用Spring Boot + Vue3框架构建。使用简单，该项目可以生成简单滑动验证码，用于简单的网站或应用的身份验证流程中。

⚠️**注意：该项目未做严格安全性验证请勿用于高安全性要求的场景中。**

## 技术栈

- Java 8+
- Spring Boot
- Maven
- Vue3

## 特性

- 主要组件原生DOM实现，可方便移植至其它前端框架中。
- 适配Touch事件，可兼容移动设备。
- 图片分辨率、文字内容、噪声纹理密度、色彩等可灵活配置。
- 轨迹校验
- **PoW（Proof of Work）机制**：采用工作量证明机制防止暴力破解，通过调整难度系数平衡安全性与用户体验。

## PoW 机制说明

本项目采用了 **PoW（Proof of Work，工作量证明）** 机制来增强验证码的安全性，防止自动化脚本暴力破解。

### 工作原理

1. **服务端生成挑战**：生成验证码时，服务端会创建一个随机盐值（`powSalt`）和难度系数（`powDifficulty`）
2. **客户端计算证明**：前端需要根据以下公式计算出满足条件的 nonce 值：
   ```
   SHA256(hash + ":" + powSalt + ":" + nonce) 的前 N 位必须为 0
   ```
   其中 N 由 `powDifficulty` 决定（例如难度为 4，则需要前 4 位为 0）
3. **服务端验证**：后端验证客户端提交的 nonce 是否满足条件

### 配置说明

在 `application.yaml` 中可以配置 PoW 难度系数：

```yaml
captcha:
  pow-difficulty: 4 # PoW难度系数
```

- **难度系数范围**：建议设置为 3-5
  - 数值越小，计算越快，但安全性较低
  - 数值越大，计算越慢，安全性更高，但可能影响用户体验
- **默认值**：4（约需进行 16^4 = 65,536 次哈希计算）

### 安全优势

- 增加暴力破解的计算成本
- 有效防止高频自动化攻击
- 对正常用户影响较小（现代设备可在毫秒级完成计算）
